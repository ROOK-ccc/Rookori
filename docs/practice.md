# 練習・復習と教材の運用

ホームの「練習問題集」から「ランダム問題を解く」を選ぶと2タップで出題が始まります。「学ぶ」からはタクティクス、チェックメイト、エンドゲーム、テーマ別、難易度別に進めます。

## 自分の対局から練習する

1. CPU対戦の終了画面で「この対局から学ぶ」を選びます。外部の終了済み対局は、PGNファイルまたはテキストを読み込みます。一括で取り込んだ対局は「対局履歴」からそれぞれ開きます。
2. 対局で使った色を確認します。単独の局面なら、自分の手番で止めて「この局面を練習問題にする」を押します。対局全体では、クイック解析または詳細解析を始め、候補を確認します。解析・候補探索は画面の中止ボタンで止められます。
3. 復習したい候補を追加し、「追加した問題を解く」へ進みます。解答後は実戦手と推奨手の盤、白基準の評価、推奨手に対する応手を確認できます。関連テーマが確認できる問題には一般練習への案内が出ます。
4. 「今日の10問」や復習予定を開き直すと、その日の続きから取り組めます。一般問題は「あとで解く」で保存できます。「単に試した」「ヒントを使った」「手順を解き終えた」を区別して記録します。

複数手の問題では、盤の近くに相手の応手の再生と、次に自分が指す手番を表示します。解き終えたら「正解！」が残ります。手順と解説を確認し、準備ができたら「次の問題へ」を押せます。下線が付いた用語や棋譜表記は、タップ、クリック、キーボードで開けます。用語集から「棋譜の読み方」も開けます。

対局全体からの候補選びは、利用者が指した手、実戦手と推奨手の差、探索の深さ、候補手順の合法性を確認します。大きく負けていて実質的な改善が見つからない局面や、評価が比較できない局面は除外します。登録する候補は全体探索1局あたり最大5件です。同じ開始局面には共通のハッシュIDを使います。CPUやPGNの既存データから生成でき、Lichessの直接取得は停止したままです。

Stockfishがほぼ同等と評価した手は別解として扱い、候補外の着手も解析できる場合は再検証します。1手で相手を詰ませる合法手は受け付けます。一般問題では、Lichessの記録手順、1手詰めの合法な別解、運営者が追加した別解を受け付けます。一般問題のテーマ解説と個別解説は別に表示します。手順の合法性を確認しても、解説の内容や編集した手が最善であることは別途確認が必要です。

## 出題と成果の見方

「今日の10問」は未学習の専用問題4、関連する一般問題3、復習予定2、未学習テーマ1が目安です。条件を満たす問題が少ない日は一般問題で補い、同じ問題は出題一覧に一度だけ載せます。その日のリストを端末に保存します。形式を変更すると「おすすめ」「一般問題のみ」「自分の対局からの問題のみ」の日次メニューを切り替えられます。

おすすめは、最近登録した複数の対局に共通する分類や、最近の一般練習で初回に間違えたりヒントを使った問題に基づきます。得意・不得意の判定には記録数の下限があり、少数の記録から棋力や棋風を判断しません。駒損、1手詰め、応手まで確認できたナイトのフォークなどは具体的に説明し、評価値の差だけではピンやスキュアに分類しません。期間ごとの推移を出す際は、それぞれの回答数も添えます。

新しい一般問題の取得には通信が必要です。アプリをオンラインで開いたあと、その版で読み込んだ最近8分割分と目次は再利用できます。専用問題は端末内に保存され、登録済みの答えと比較できます。候補外の手の確認などStockfishの取得が必要な場合は接続が必要です。練習記録、保存した一般問題、日次リストは一括バックアップに含まれます。

## 一般問題データ

- 取得日 2026-11-27。公式の [Lichess Open Database](https://database.lichess.org/#puzzles) の練習問題エクスポート。ライセンス [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。
- 入門（1000未満）1,000、初級（1000〜1399）2,000、中級（1400〜1799）1,500、上級（1800以上）500。各テーマ別の件数と分割情報は [目次データ](../puzzles/catalog.json) に記録しています。テーマは重複して付くことがあります。
- 問題レート400〜3000、人気度75以上、解答数100以上、レート偏差110以下を採用します。配布順で目標件数がそろうまで検証し、開始局面の重複を除外します。相手の一手を適用した局面を出題に使い、残りを合法手として再生します。元の問題IDを維持し、対局URLは収録しません。
- Node.js 24で、`node import-puzzles.cjs lichess_db_puzzle.csv.zst YYYY-MM-DD puzzles` を実行します。CSVにも対応します。目標数がそろった時点で読込を止めます。公開ビルドでは100問ずつ分割し、必要になったファイルだけを読み込みます。
- 今回の収録枠は、取得した公式ファイルの先頭部分から満たしました。収録した5,000問はすべて再生検証済みです。配布データ全体から人気度順の上位を選んだ集計ではありません。

## ローカル編集

1. Windowsで `start-editors.bat` をダブルクリックし、画面上部の「練習問題エディターへ」を選びます。両方のエディターを画面上部から移動できます。
2. 問題ID・編集済みの問題名で検索できます。「個別解説が未入力の問題のみ」で対象を絞り込みます。盤の下で着手を再生できます。
3. 編集途中は「下書きを保存」を押します。「合法手を検証して盤を更新」で、正解と別解の手順や詰みの終点、盤面から組み立てた解説案を確認します。公開時の解説は「自動生成」「確認済み」「独自執筆」から選べます。「確認済み」と「独自執筆」では文章を入力してください。解説の確認状態で検索でき、既存の個別解説は旧形式のままでも保持します。
4. 公開状態と差分を確認して「作業フォルダーに反映」を押し、確認画面で承認します。現在の問題だけを `practice-edits.json` に保存します。予備として変更ファイルをダウンロードできます。自作の入門問題は従来のエディターで編集できます。
5. `node publish.cjs --target cloudflare-preview` で確認します。編集ツール・下書き・編集元JSONは配信対象から外し、公開状態の問題だけを分割データに出力します。

## SEOと計測

`/practice/` に練習方法と学習画面の導線を掲載し、タクティクス、1手詰め、終盤、棋譜復習などの記事を正式サイトのサイトマップに載せます。各利用者の問題や棋譜は静的ページに生成しません。

| イベント | 発生条件 |
| --- | --- |
| `personal_practice_generated` | 1件以上の新しい専用問題を保存 |
| `personal_practice_start` | 端末にある専用問題を表示 |
| `personal_practice_complete`・`personal_review_complete` | 専用問題を初めて、または過去に回答した問題で正解 |
| `general_practice_start`・`general_practice_complete` | 一般問題を表示、または手順を最後まで解く |
| `daily_practice_complete` | 日次メニューのいずれかで10問正解した日につき1回 |
| `practice_recommendation_start` | おすすめの一般問題を表示 |
| `game_review_complete` | 終了済み対局の全体解析で不足していた局面を解析し、最終着手前まで評価を取得 |

同意後の固定イベントだけを送ります。FEN、棋譜、対局ID、個別問題ID、回答は送信項目に含めません。GA4の「探索」で、完了イベントのアクティブユーザーを学習完了者、別セッションで練習開始・完了が再発したユーザーを再訪学習者として集計します。専用練習利用率は、同期間内の `personal_practice_start` の利用者を `dashboard_view` の利用者で割った値を参考にできます。公開後にリアルタイムで確認し、拡張計測による二重計測を避ける設定は [既存の計測手順](opening-editor.md#計測と集計) を参照してください。
